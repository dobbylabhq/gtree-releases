版本说明

每个版本新增、改进和修复了什么。已经装了 gtree 的话,有新版本时侧栏底部会提示「更新并重启」。

v0.3.19最新

2026年10月28日 · 终端里按住 ⌘ 就能看图,能打开不是 Git 仓库的文件夹,项目可以拖动排序

改进#

  • 内嵌终端里的图片能直接看了:按住 ⌘ 把鼠标放到图片路径(比如 /tmp/shot.png、~/Desktop/a.jpg,或相对当前目录的路径)或 Claude Code 里粘贴图片后显示的「[Image #3]」上,旁边就浮出预览;⌘ 点击打开大图,还能「在 Finder 中显示」。Agent 截的图、你粘的图,不用再去 Finder 里翻。
  • ⌘O 能打开不是 Git 仓库的普通文件夹:照样能开 AI 会话、终端、看文件。开始页和「提交历史」页有「创建 Git 仓库」,点一下就变成 Git 项目。
  • 侧栏的项目可以拖动排序,下次打开还是这个顺序。
  • 侧栏底部的更新提示卡片不再显示不全。下次有新版本时,点卡片上的「查看完整更新说明」就能看新版本改了什么。

修复#

  • Claude Code 用深色主题时,提问里的问题正文在 gtree 的浅色终端里是白字白底,一片空白。现在终端会把和底色太接近的文字自动调到看得清。
  • 点侧栏「已合并」分组里的一条线,它会跳到上面的列表里,离开刚点的位置。
  • 从 0.3.7 或更早的版本升级上来后,第一次打开 gtree 会闪退一次。

v0.3.18

2026年10月28日 · 文件页能跳到定义,搜索挪进右面板,Diff 的文件列表能收起

改进#

  • 文件页能跳到定义:按住 ⌘ 悬停名字会出下划线,⌘ 点击、F12 或右键「跳转到定义」就跳过去并选中它,定义在别的文件就在文件页打开那个文件。同名的定义不止一处时弹出选择框,列出路径、行号和那一行代码。⌃- / ⌃⇧- 后退、前进,回到原来的文件和那一行。支持 Rust、JavaScript / TypeScript、Python、Go,不用装任何语言服务。每个 worktree 第一次打开源文件时会先在后台准备一会儿,准备好之前按了不会跳。
  • 跨文件搜索(⌘⇧F)挪进了右面板,成为「文件 / 改动 / 搜索」第三个标签,不再挡住正在看的代码。点一条结果在主区打开,结果留在面板里,可以接着点下一处。
  • Diff、未提交改动、「AI 每一轮」左边的文件列表可以收起成一条窄栏,给代码让出地方,下次打开还是收起的。
  • ⌘T 和标签条上的「+」多了「打开终端」,排在新开 Claude Code、新开 Codex 之后。

修复#

  • Diff 右边内容的文件顺序和左边的文件树对不上:比如 Dockerfile 排在 config/ 目录前面,左边树里它却在最下面。
  • 长行横向滚动时,代码和底色一直画到右面板的边线上,看着像被面板盖住了一截。
  • 从搜索结果打开文件时,有时没有定位到命中的那一行。

v0.3.17

2026年10月23日 · Diff 能横向滚动,⌘⇧P 命令面板和 Markdown / PDF 预览,侧栏收起也看得见在用的 worktree

改进#

  • Diff 里的长行不再被截掉:内容区可以横向滚动(触控板横滑,或拖底部的滚动条),行号、文件标题和「⋯ N 行未改动」钉在左边不跟着跑。「AI 每一轮」和未提交改动的详情也一样。
  • 新增 ⌘⇧P 命令面板:和 ⌘P 是同一个浮层,输入以 > 开头就是找命令,每条带快捷键,只列眼下做得了的。
  • 文件页能预览 Markdown(头部切「预览 / 源码」)和 PDF(按页显示)。「Markdown 预览」和「PDF 预览」都是内置插件,默认开着,设置里新增的「插件」一节可以关。
  • 历史对话(⌘Y)的搜索框右边多了「当前 worktree」开关(⌘E),只看在这条线里聊过的,跨启动记住。
  • 侧栏里收起的项目仍会露出在用的 worktree:开着 tab 的、AI 在跑的、在等你的,不再被藏掉,点一下就切过去。
  • 配色重调:AI 相关的颜色从紫色换成 logo 的深青,分支图里各条分支的颜色淡了一些,深色主题下红、绿、琥珀换成亮一档的。

修复#

  • 关掉 ⌘P / ⌘⇧P 浮层后快捷键没反应;在 ⌘P、⌘Y、新开会话的选择框里点搜索框,浮层会直接关掉。
  • 新建的目录(还没加进 git 的)在文件树里显示成一个没有名字的文件,里面的文件一个都不出现。现在逐个列出;被 .gitignore 忽略的文件也显示出来(灰色),node_modules 这类被忽略的目录点开才列里面的内容。
  • 「待处理」里(「也许要留意」、「正在干活」行下、关系图的连线)不再列收件会话已经结束、永远送不到的留话,gtree 代发的「[自动]」通知也不再列出;「我这一轮做完了」的自动通知不再每轮叠一条。
  • 当前项目收起后,选中的 worktree 带着灰底夹在一排项目名之间,看着像项目被选中了。

v0.3.16

2026年10月15日 · Diff 一页看完所有文件,文件页能看图和提交历史,项目能改名

改进#

  • Diff 像 GitHub 的 PR 页一样,所有改动的文件连成一长条,往下滚就能看完全部改动。点左边的文件,直接滚到它;点文件标题可以收起或展开它。「显示全文 / 仅看变更」改成每个文件单独切换。「AI 每一轮」和未提交改动的详情也一样。
  • 在 Diff 里选中文字后,右上角会浮出「复制选中」。复制时会跳过文件标题和「⋯ N 行未改动」这类折叠行,只留代码。
  • 在文件页打开图片(PNG、JPG、WebP、GIF、SVG 等),直接显示成图,自动缩到放得下。SVG 可以切到「看源码」。特别大的图片不预览。
  • 文件页新增「提交历史」:列出改过这个文件的提交,文件改过名也找得到。点一条,去 Diff 看那次提交改了什么。
  • 侧栏里右键项目,选「重命名」就能原地改名。按 ↩ 保存,按 esc 取消,留空则恢复成文件夹名。「待处理」、系统通知,以及 gtree 告诉 agent 的「你在项目 …」都会用新名字。

修复#

  • 切回「待处理」的头几秒,列表还是上次离开时的样子,和侧栏的角标对不上。
  • 从某个 worktree 的文件夹打开仓库时,「待处理」里同一个仓库会出现两次,在等你的 agent 也跟着出现两次,gtree 告诉 agent 的项目名也会说错。

v0.3.15

2026年10月15日 · agent 干活时更省 CPU,发给 agent 的话也有英文了

改进#

  • agent 在干活时,gtree 自己占的 CPU 少了一半。agent 状态的转圈、铃铛,原来按屏幕刷新率重画,现在每秒约 12 次。实测 3 个 agent 在干活、1 个在等你时,gtree 从 8.6% 降到 4.4%(单核);什么都没在跑时仍在 1% 以下。
  • gtree 发给 agent 的话跟着界面语言走:中文界面发中文,其他语言发英文。包括同一个 worktree 里别的会话刚改过某个文件时的提醒、别的会话的留话、会话开头「谁在干什么」的说明,以及 gtree MCP 工具的说明。
  • 开始页「还没连上 Claude Code」的提示改成一张卡片:说明占满一行,按钮另起一行,不再被挤成窄窄一列。
  • 首次打开的引导文字跟上了现在的界面:同一个 worktree 里的 agent 改同一个文件前会先商量;「AI 每一轮」和 ⌘Y 代替了原来的时间线;「待处理」代替了原来的协作视图。
  • 状态的悬停提示开头从「Claude ·」改成「AI ·」,Codex 的会话也用它。

修复#

  • 空仓库里,文件树的加载占位一直在闪,不会消失。
  • 界面是英文或日文时,「历史对话」回放里的工具步骤(如「编辑 src/theme.ts」)显示成中文。
  • 开始页的同改清单里,文件路径可能被挤得看不见。现在涉及的 worktree 放到第二行。
  • 「待处理」不再提示「去工作台看」(工作台已经没有了),只写还有几组。
  • 设置里 Claude Code 各个 hook 的说明不再提工作台和时间线。团队版的说明不再列「队友」(它已经在免费版里),并写明中转服务器只转发同步信息、不存储数据。

v0.3.14

2026年10月15日 · 重开还是关闭前的样子,点一下就能看 diff

改进#

  • 关掉 gtree 再打开,之前打开着的项目、停在哪个项目、每个项目选中的 worktree 都还在,不用重新加一遍项目。
  • 开始页的「看改动」,以及在右边「改动」里点一个文件,都会在中间直接打开 diff:左边是改动的文件,右边是内容,新建的文件也能看。暂存和取消暂存只用行尾的 + / −,点文件本身不会再把它暂存。
  • 开始页的「用编辑器打开」改成「打开文件」:右边切到文件树,同时弹出 ⌘P 找文件。选中的文件在 gtree 里打开,可以直接改、保存。
  • 分支变基后和远端不一致时,开始页不再同时提示「拉取」和「推送」,改成一条「变基后和远端的这条分支不一致了」,按钮是「推送(覆盖远端)」,点了先确认。远端有别人新推的改动时不会出现这一条。
  • 一轮详情里很长的回复默认只显示 4 行,可以展开,下面的改动不会再被挤出屏幕。
  • 侧栏项目、「已合并」、「AI 临时工作区」、「AI 每一轮」、开始页的同改清单,展开和收起都有过渡动画,展开时一行一行依次出现。「AI 每一轮」收起时标题不动。

修复#

  • 全局搜索里点文件范围框,搜索框不会再被关掉;⌘⇧F 现在总是打开搜索,再按一次不会把它关掉。
  • 侧栏选中的线有时会跳到另一条。
  • 开始页的同改清单只列和当前这条线有关的,换到别的线不会再带着别人的清单。
  • 「AI 每一轮」里换会话的分隔线压住下一行文字。

  • 「改动」标签重新排版。工作区干净时,上面只留一行「未提交改动　干净」,空间都给下面的「AI 每一轮」。「全部丢弃」收进了「⋯」菜单。
  • 「AI 每一轮」每轮占两行:第一行是你的提问和时间,第二行是改了几个文件、是哪些(如「3 个文件 · root.rs 等」)。左边的彩色竖条去掉了,不同会话之间用一条线隔开。「显示没改文件的轮」和「旧版快照」收进了「⋯」菜单。

v0.3.12

2026年10月14日 · 新布局:点一条线就知道下一步做什么,侧栏显示 MR 状态

改进#

  • 界面重新布局。左边侧栏只剩「待处理」「提交历史」和你的项目。点项目里的一条线就进到它的主页:开着会话的进对话,闲着的显示这条线的开始页。原来的「工作台」取消了。快捷键:⌘1 待处理,⌘2 当前 worktree,⌘3 提交历史。
  • 开始页列出这条线现在的状况,每种情况配一个按钮:已经合并(删除 worktree / 换一条新分支)、别处也在改同一个文件(看是哪些)、有没提交的改动(看改动)、远端有新提交(拉取)、还没推送(推送)、开着的 MR(打开 MR)、还没有 MR(创建 MR)、落后于主分支(变基)。下面一排是新开 Claude Code / Codex、打开终端、用编辑器打开。
  • 右边的面板分成「文件」和「改动」两个标签(⌥⌘B 开合,⇧⌘E / ⌃⇧G 切换)。「改动」里是没提交的文件(在这里暂存、提交)和 AI 的每一轮,点一轮就在中间看它改了什么。原来的「改动」视图改名「提交历史」。
  • 侧栏的分支后面显示 MR 状态:没合并的是 pull request 图标,已合并的是浅色的合并图标。鼠标停上去能看到编号、标题和链接,点一下在浏览器打开。用的是你电脑上已经登录的 glab 或 gh,支持 GitLab(包括公司自建的)和 GitHub;两个都没装就不显示。
  • 侧栏每条线的行尾只放一个标记:AI 会话的状态(在干活、在等你等),别处也在改同一个文件(琥珀色 △),或者没提交的改动有多少行(如「+24 −3」)。鼠标停上去有说明。
  • 分支已合并、也没在用的线,收进侧栏底部的「已合并 · N」。在平台上 squash 合并、git 自己认不出来的也算。
  • 在侧栏右键一条线,打开 Git 菜单(推送、拉取、提交、切分支、删除 worktree 等)。worktree 多的时候,项目名固定在顶上,随时能点它收起。
  • 侧栏里 AI 正在干活或在等你的线,不管在哪一页,点它都直接打开那个对话。
  • AI 页不再自动启动 Claude Code,只是点进来看一眼不会多出一个会话。要开会话就点开始页的「新开 Claude Code」或按 ⌘T(装了 Codex 时可以选)。
  • 历史对话改成 AI 页顶部的小窗(⌘Y):直接打字搜索,↩ 接着聊,⌘↩ 只看不接。在列表里单击一条也是接着聊。
  • 用 ⌘W 关掉正在跑 Claude Code 的标签页时会先问一下。可以勾「不再询问」,之后在设置里改回来。

修复#

  • 「答完了,等你回复」的铃铛,切到那个终端标签页就会消失,不用再发一句话。
  • 在「待处理」点一行,会切到那件事所在的会话标签页;列表刷新时,键盘选中的那一行不会再跳走。
  • 快速连点顶栏里的按钮,不会再把窗口放大。
  • 终端里被折成两行的长网址,按住 ⌘ 点击也能打开了。

v0.3.11

2026年10月13日 · 工作台一眼看出先管哪个,「待处理」重做

改进#

  • 工作台改成每个 worktree 一行、按急缓分组:要你处理的(在等你、合并冲突)排最前,没改动、没有 AI 在干活的折起来,分支已合并的也一样。第一行是完整的分支名,第二行是 worktree 名和改了什么;按钮鼠标移上去才出现。
  • 两个 worktree 改了同一个文件,改为写在那一行里、点开看文件清单,不再常驻橙色横幅。
  • 工作台、状态栏、文件树和搜索里的状态颜色只剩四种意思:红色是要你处理,琥珀色是有风险,紫色是 agent 在干活,绿色是已暂存。
  • 连上 Claude Code 或 Codex 后,agent 在会话开头(以及你提到 worktree 时)会拿到一份可以直接复用的 worktree 清单,不用再新建一个。
  • 「待处理」重做:点一行就进到那个会话,也可以用 ↑↓ 选、↩ 进入、⌫ 收起。
  • 去掉了「待处理」右边的「AI 往来」栏:agent 之间正在问的问题、给对方的留话,改为挂在相关那一行下面。「也许要留意」里还会出现:等另一个 agent 回答等太久、留话一直没送到、你问的 agent 回答了(点一下就地展开)。
  • 「待处理」的列表和项目关系图各自滚动;关系图可以双指拖动、捏合缩放,双击空白处整张图放进窗口。
  • 跨文件搜索(⌘⇧F)改版:边输入边出结果,按文件分组、命中处高亮;可以区分大小写、全词匹配、只搜有未提交改动的文件,也可以用 *.rs !tests 这样的写法限定范围。
  • 内嵌终端:按住 ⌘ 点链接直接打开;⌘← / ⌘→ 跳到行首 / 行尾,⌥← / ⌥→ 按词移动;从 Finder 拖文件进来会填入路径,拖进图片 Claude Code 也能认出来。
  • 打开文件时,文件树会自动展开到那个文件。
  • AI 页的历史对话按今天 / 昨天 / 近 7 天 / 更早分段,滚动时分段标题留在顶上。

修复#

  • gtree 没开着的时候(比如 ⌘Q 退出后),在别的终端里用 Claude Code 或 Codex,不会再收到 gtree 的通知。
  • 点「继续这个会话」时,如果它已经开在 gtree 的某个终端标签页里,会直接切过去。
  • 搜索结果按 ↩ 能打开了;路径里有中文等字符的结果也能打开了;新结果不会再被前一次搜索替换掉。
  • 带换行的会话标题不再把历史对话列表撑乱。
  • 项目关系图不再被撑宽、右边被裁掉;不再出现名为「/」的项目。

2026年10月10日 · 打开的文件可以直接改了

新增#

  • 不是 UTF-8 编码的文件以只读方式打开。

改进#

  • 侧栏、文件面板、AI 历史栏的收起 / 展开按钮统一成同一个面板图标。

v0.3.9

2026年10月10日 · 连上 Codex,agent 之间自己商量,新增「队友」

新增#

  • 连上 Codex:在设置里点「连上 Codex」,Codex 会话就和 Claude Code 一样 —— 在干什么、什么时候在等你一眼看清,在等你的进「待处理」,每一轮的改动都记下来、可以按轮恢复,不用再去 Codex 里逐条批准。
  • AI 视图的「+」可以新开 Codex,和 Claude Code 并排跑在内嵌终端里;「历史对话」也能搜到、回放 Codex 的会话。
  • 同一个工作区里的 agent(Claude Code 或 Codex)互相知道对方:一个改了另一个也改过的文件,对方会自动收到通知;要改同一处时会给对方留话、商量谁先改,先改的一方做完会告诉另一方。
  • 新增「队友」,默认关、按仓库开:最近有别人提交的仓库,侧栏项目下会出现「队友」一节,点「开启」、再点「开始同步」后,你和队友经团队自己的 git 仓库互相看到还在写的代码(包括没提交的),点开就能看对方的改动。
  • 和队友改到同一处时,你的 AI 会在动手前先停下来问你;「待处理」里也会提醒,点「看对方的改动」直接看。
  • AI 可以给队友留话:对方本人看过、点「交给我的 AI」后才会交给他的 AI,回复会自动回到发问的那个 AI。
  • 队友之间的内容都带签名,留言只有收件人能解开,仓库里的其他人冒充不了队友;队友的身份变了,要你确认是本人才继续接收。

改进#

  • 状态栏的「别处开着的 AI」点开是一份会话列表:问的什么、多久前、在干什么,点一行就切到对应的终端;认不出在哪的,打开这段对话的回放。
  • 文件树右键可以在浏览器中打开、用默认程序打开、在 Finder 中显示、在终端中打开(在 gtree 的内嵌终端里)和复制路径。

修复#

  • 引导翻页时不再闪出别的画面;最后一页的动图换成了「连上 Claude Code」的演示。
  • 同一个工作区并行跑长命令时,文件不再被算到别的会话名下;测试输出里的「0 failed」也不再被当成报错。
  • Claude Code 的连接说明里,去掉了应用实际不会显示的「出错 / 卡住」状态。
