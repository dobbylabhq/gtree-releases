# プライバシーポリシー

最終更新: 2026-10-16

## 概要

gtree は、お使いのコンピューターの中だけで動くデスクトップアプリです。gtree のアカウントやログインはありません。**gtree がソースコードをアップロードすることはありません。** ファイル名、パス、リポジトリ名、git の設定、Claude Code や Codex での会話も、私たちには一切送信されません。アプリが DobbyLab に送るのは、通常のアップデート確認に添える匿名の利用統計だけで、ワンクリックでオフにできます。

本ポリシーは、gtree アプリ、ウェブサイト(https://gtree.dobbylab.com)、ダウンロードサーバー(https://gtree-dl.dobbylab.com)を対象とします。運営は **DobbyLab**(個人開発者 tzyito。法人ではありません)です。

## アプリが送信するもの

gtree は起動の 10 秒後にアップデートを確認し、その後は 6 時間ごとに確認します(正式版のみ)。確認では `gtree-dl.dobbylab.com` から小さなバージョン情報ファイルを取得します。このサーバーにつながらない場合は、同じファイルを GitHub から直接取得します。その際、利用統計は送りません。

匿名の利用統計がオンのときは、アップデート確認に次の 4 つの値を添えます。

- **ランダムなデバイス ID**:初回に Mac 上で生成する 32 桁の 16 進数で、`~/.gtree/device-id` に保存されます。ハードウェア情報、お名前、Apple ID などから作られたものではありません。
- **gtree のバージョン**(例:`0.4.1`)
- **CPU アーキテクチャ**(`aarch64` または `x86_64`)
- **macOS のバージョン**(例:`15.3`)

これらは、1 日あたりの利用デバイス数、新規デバイス数、バージョンごとの利用状況を数えるためだけに使います。これ以外の情報は含まれません。

**送信の前に必ずお知らせします。** 正式版を初めて起動すると、サイドバーに「匿名の利用統計」カードが表示されます。このカードが表示されるまで、利用統計は一切送信されません。

アップデートをダウンロードするときも `gtree-dl.dobbylab.com` を経由します。その際は、そのバージョンの 1 日のダウンロード数が 1 増え、国別の件数も別に 1 増えます。

## アプリが送信しないもの

gtree が DobbyLab に次のものを送ることはありません。

- ソースコード、差分、ファイルの内容
- ファイル名、フォルダのパス、リポジトリ名、リモート URL
- git の設定、ユーザー名、メールアドレス、コミット履歴
- Claude へのプロンプト、Claude の返答、セッション履歴
- クラッシュレポート(gtree にクラッシュレポート機能はありません)

## 利用統計をオフにする方法

次のいずれかでオフにできます。オフにしてもアップデート確認はこれまでどおり行われ、上記の 4 つの値が添えられなくなるだけです。

- 初回起動時のカードで **統計をオフ** をクリックする
- **設定**(⌘,)で **匿名の利用統計** をオフにする
- 空のファイル `~/.gtree/telemetry-off` を作成する
- 環境変数 `GTREE_NO_TELEMETRY=1` を付けて gtree を起動する

アップデート確認そのもの(=私たちのサーバーとの通信すべて)を止めたい場合は、`GTREE_NO_UPDATE=1` を付けて起動してください。その場合、アップデートは手動で行う必要があります。

## Mac の中にだけ保存されるデータ

gtree の作業データはローカルに保存され、DobbyLab には送信されません。

- **`~/.gtree/`**:設定、デバイス ID、ローカルデータベース(`gtree.db`)。データベースにはプロジェクトの一覧と、Claude Code と連携している場合は Claude の各ターンの記録(プロンプト、Claude の最後のまとめ、変更されたファイル)が入ります。後から始めたセッションが、前回の続きから作業できるようにするためのものです。
- **各リポジトリの git フォルダ内**:Claude セッションの状態ファイル(`.git/gtree/`)と、`refs/gtree/agent/` 以下のチェックポイントコミット。gtree がこれらの ref をどこかへ push することはありません。
- **Claude Code 連携**:インストールすると、gtree は `~/.claude/settings.json` に自分用のフックを追加し、小さなスクリプトを 3 つ(既定では `~/.claude/gtree/`)置き、ローカルの MCP サーバーを Claude Code に登録します。フックはイベントを Mac 上の gtree に渡すだけで、外部のサーバーには接続しません。gtree が追加・削除するのは自分の項目だけで、ご自身や他のツールが登録した項目には触れません。
- **Codex 連携**:Codex をつなぐと、gtree は `~/.codex/hooks.json` に自分用のフックを追加し、小さなスクリプトを 3 つ `~/.codex/gtree/` に置き、Codex 自身のコマンドでローカルの MCP サーバーを登録します。あわせて、Codex 側で一つずつ承認しなくて済むよう、`~/.codex/config.toml` でこれらのフックを信頼済みにします。gtree から Codex を開く前には、そのリポジトリを Codex の信頼済みプロジェクトとして記録します(`config.toml` の `[projects."<リポジトリのパス>"]`。すでに項目がある場合は変更しません)。Claude Code と同じく、フックはイベントを Mac 上の gtree に渡すだけで外部のサーバーには接続せず、gtree が追加・削除するのは自分の項目だけです。「履歴」で Codex のセッションを検索・再生するときは、Mac 上の `~/.codex/sessions/` にある記録を読み込みます。
- **通知**は Mac の通知センターに表示されます。表示する前に、通知を許可するかどうかをお尋ねします。

**設定 → gtree を削除** を使うと、Claude Code と Codex の連携、各リポジトリ内の gtree のデータ、`~/.gtree/` が削除されます。データを残す選択もできます。Codex に記録した信頼済みプロジェクトは残るので、不要であれば `~/.codex/config.toml` から削除してください。

## AI 機能、Claude Code と Codex

gtree は独自の AI モデルを持たず、AI サービスを直接呼び出すこともありません。Mac 上のターミナルで、**ご自身の** `claude` または `codex` コマンドラインツールを起動するだけです。Claude に入力した内容や Claude が読み込むコードは、お客様と Anthropic との契約に基づいて Claude Code が処理します。Codex の場合も同様に、お客様と OpenAI との契約に基づいて Codex が処理します。いずれも DobbyLab を経由することはありません。

複数のセッションが互いの状況を把握できるように、gtree は Mac 上の一部の情報をお使いの Claude Code または Codex のセッションに渡します。ほかのセッションが何をしているか、どのファイルを変更したか、過去のターンのプロンプトとまとめなどで、ほかのプロジェクトのこうした情報が含まれることもあります。これらはその会話の一部となり、AI に伝えるほかの内容と同じく、お客様と Anthropic(Claude Code)または OpenAI(Codex)との契約に基づいて処理されます。DobbyLab に送信されることはありません。

## git の操作

gtree は fetch、pull、push などの操作に、システムの `git` を使います。リポジトリを開いている間は、約 3 分ごとにバックグラウンドで `git fetch` を実行します。これらの通信は、ご自身の認証情報を使って、Mac から設定済みのリモート(GitHub、GitLab、自社サーバーなど)へ直接行われます。DobbyLab がその内容を目にすることはありません。

## チームメンバー(初期設定はオフ)

「チームメンバー」は、まだ作業中のコードをチームメンバーと見せ合う機能です。**初期設定はオフ**で、リポジトリごとにオンにします。サイドバーに「チームメンバー」が表示されるのは最近ほかの人がコミットしているリポジトリだけで、「オンにする」を押し、説明を読んで「共有を始める」を押したときにはじめて有効になります。この設定はそのリポジトリの git 設定(`gtree.shareLive`)に保存されます。

オンにすると:

- **同期されるもの**:そのリポジトリでまだチームに渡していないコード(未コミットの変更、新しいファイル、まだプッシュしていないコミット)とブランチ名が、**チーム自身の git リモート**の、ブランチとしては表示されない場所(`refs/gtree/`)にプッシュされます。`.gitignore` で除外されたファイル、1MB を超える未追跡ファイル、AI の一時ワークスペースは対象外です。変更後は自動でプッシュし、メンバーの分も定期的に取得します。
- **見られる人**:そのリモートの読み取り権限を持つ人と、ホスティングしているサービス(GitHub、GitLab など)は、同期されたコードの内容を見ることができます。DobbyLab は関与せず、私たちのサーバーも使いません。
- **身元**:なりすましを防ぐため、gtree は Mac 上でお客様の git メールアドレス用の鍵を作成します(秘密鍵は `~/.gtree/team-keys/` に本人だけが読める形で保存され、このコンピューターの外に出ることはありません)。公開鍵は、お名前とメールアドレスとともに同じリモートにプッシュされます。同期される内容にはすべてお客様の署名が付きます。
- **伝言**:AI がチームメンバーに残す伝言も同じリモートを経由し、**エンドツーエンドで暗号化**されるため、読めるのは受け取る本人だけです。リポジトリのほかの人には、誰宛ての伝言があることしかわからず、内容は見えません。新しい伝言は、受け取る本人が読んで確認してからはじめて本人の AI に渡されます。お客様の AI が尋ねたことへの返事は、尋ねた AI にそのまま戻ります。AI に渡されたあとは、受け取った人と AI サービス提供者との契約に基づいて処理されます。
- **オフにする**:いつでもオフにできます。同期は止まり、プッシュ済みの内容はリモートから取り消されます。メンバーがすでに取得したコピーは取り戻せません。

## ウェブサイト

- ウェブサイトは静的なサイトで、**GitHub Pages** でホストしています。
- アクセス数の計測に **Cloudflare Web Analytics** を使っています。Cookie は使いません。読み込まれるのは `gtree.dobbylab.com` 上だけです。
- ページを開くと、最新のバージョン番号を `gtree-dl.dobbylab.com` に問い合わせます。その際、1 日あたりのページ表示回数(国別)が 1 増えます。
- 表示テーマ、言語の選択、アーリーバード登録済みかどうかの 3 つを、ブラウザのローカルストレージに保存します。これらはブラウザの中にとどまり、私たちには送信されません。
- サイト独自の Cookie は使用していません。

## ダウンロードサーバー

`gtree-dl.dobbylab.com` は、公開している GitHub Releases からインストーラーとインストールスクリプトを中継する Cloudflare Worker です。リクエストごとに、種類(ダウンロード、インストールスクリプト、バージョン確認、ページ表示)・バージョン・国別の **1 日の件数** を 1 増やします。

- 国は、Cloudflare が IP アドレスから判定した 2 文字のコードです。**IP アドレスは保存しません。**
- 件数は日ごとに集計しており、ダウンロード 1 件ごとのログは残しません。
- デバイス単位で保存するのは、前述のアップデート確認による次の 2 つだけです。「1 デバイス 1 日 1 行」のデータ(デバイス ID、バージョン、CPU 種別、macOS バージョン、国)と、新規デバイス数を数えるために各デバイスが初めて現れた日付を記録する 1 行です。

## チームプランのアーリーバード登録

ウェブサイトでチームプランのアーリーバードに登録すると、次の情報を保存します。

- メールアドレス
- 選択したチームの規模(任意)
- 登録日
- 国(Cloudflare が IP アドレスから判定。IP アドレスは保存しません)

メールアドレスはチームプランのリリースをお知らせするためだけに使い、第三者には渡しません。登録リストを読み出せるウェブページや API はなく、エクスポートできるのは運営者だけです。同じアドレスで再登録しても、重複して保存されることはありません。

## 第三者のサービス

| サービス | gtree での役割 | 扱いうる情報 |
|---|---|---|
| Cloudflare | ダウンロードサーバーとそのデータベース(D1)、Web Analytics、DNS、`support@dobbylab.com` 宛メールの転送 | `gtree-dl.dobbylab.com` へのリクエスト、サイトへのアクセス(Web Analytics)、アーリーバード登録、サポート宛のメール |
| GitHub | ウェブサイト(GitHub Pages)とリリースファイルのホスティング | サイトへのアクセス、GitHub へ直接フォールバックしたリクエスト |
| Anthropic | Claude Code の提供(インストールとログインはご自身で行います) | Claude Code に共有した内容(Anthropic の規約に基づく)。DobbyLab は関与しません |
| OpenAI | Codex の提供(インストールとログインはご自身で行います) | Codex に共有した内容(OpenAI の規約に基づく)。DobbyLab は関与しません |

各サービスは、それぞれのプライバシーポリシーに従ってデータを扱います。

## 保存期間

- **Cloudflare D1 上の日別の件数とデバイス単位のデータ**:現在、自動削除の仕組みはありません。私たちが削除するまで保存されます。
- **アーリーバード登録**:チームプランがリリースされ不要になるまで、またはご本人から削除の依頼があるまで保存します。
- **Cloudflare Web Analytics、Cloudflare のインフラのログ、GitHub Pages のログ**:Cloudflare および GitHub の各ポリシーに従います。
- **Mac 上のデータ**:ご自身で削除するか、gtree をアンインストールするまで残ります。

## お客様の選択と権利

- **利用統計**:上記の方法で、いつでもオフにできます。
- **アーリーバード登録**:登録したアドレスから support@dobbylab.com にメールをいただければ、削除します。
- **デバイス ID**:ID はランダムでお客様とは結びついていないため、私たちの側で「あなたのデータ」を特定することはできません。記録の削除をご希望の場合は、`~/.gtree/device-id` の内容をお送りください。このファイルを削除すると、次回から新しい ID が生成されます。

## 子どもの利用について

gtree は開発者向けのツールで、13 歳未満の方を対象としていません。子どもの個人情報を意図的に収集することはありません。お子さまがアーリーバードに登録したと思われる場合はご連絡ください。削除いたします。

## ポリシーの変更

gtree が収集する情報を変更する場合は、その変更をリリースする前に本ページと冒頭の日付を更新します。アプリでの情報収集は、今後も事前にお知らせしてから行います。
