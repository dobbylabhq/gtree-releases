# リリースノート

各バージョンの追加・改善・修正です。gtree をお使いの場合、新しいバージョンが出るとサイドバー下部に「更新して再起動」が表示されます。

## v0.3.19 (2026-10-28) — ターミナルで ⌘ を押すだけで画像を表示、Git リポジトリでないフォルダも開ける、プロジェクトをドラッグで並べ替え

### 改善
- 内蔵ターミナルの画像をその場で見られるようになりました。⌘ を押しながら画像のパス(`/tmp/shot.png`、`~/Desktop/a.jpg`、今のフォルダからの相対パスなど)や、Claude Code で画像を貼り付けたときに出る「[Image #3]」にマウスを合わせると、横にプレビューが出ます。⌘ クリックで大きく開き、「Finder で表示」もできます。Agent が撮ったスクリーンショットや貼り付けた画像を、Finder で探す必要はもうありません。
- ⌘O で Git リポジトリではない普通のフォルダも開けるようになりました。AI セッションやターミナル、ファイルの表示はそのまま使えます。スタートページと「履歴」ページの「Git リポジトリを作成」を押すと、Git プロジェクトになります。
- サイドバーのプロジェクトをドラッグで並べ替えられるようになりました。次に開いたときもその順番です。
- サイドバー下部のアップデートのカードが途中で切れなくなりました。次に新しいバージョンが出たときは、カードの「更新内容をすべて見る」から変更点を確認できます。

### 修正
- Claude Code をダークテーマにしていると、質問の本文が gtree の明るいターミナルで白地に白い文字になり、何も表示されていないように見えていた問題を修正しました。背景に近すぎる色の文字は、ターミナルが自動で読める色に調整します。
- サイドバーの「マージ済み」グループの行をクリックすると、上の一覧に移動してクリックした場所から離れてしまう問題を修正しました。
- 0.3.7 以前のバージョンから更新した後、初回の起動で一度だけ gtree が強制終了する問題を修正しました。

- ファイルをまたいだ検索(⌘⇧F)を右パネルに移し、「ファイル / 変更 / 検索」の 3 つ目のタブにしました。読んでいるコードを覆わなくなりました。結果をクリックするとメイン画面で開き、結果はパネルに残るので、続けて次の箇所を開けます。

### 修正

- 長い行を横にスクロールすると、コードと背景色が右パネルの境界線まで描かれ、パネルに一部が隠れているように見えていた問題を修正しました。

## v0.3.16 (2026-10-15) — 差分はすべてのファイルを一続きに、ファイル画面で画像と履歴を表示、プロジェクト名も変更可能に

### 改善

- 状態のツールチップの先頭を「Claude ·」から「AI ·」に変えました。Codex のセッションにも使われるためです。

## v0.3.12 (2026-10-14) — 新しいレイアウト:ラインを選べば次にやることがわかる、サイドバーに MR の状態

### 改善
- 画面の構成を変えました。サイドバーは「対応待ち」「コミット履歴」とプロジェクトだけになりました。プロジェクト内のラインをクリックするとそのホームが開き、セッションがあれば会話、なければそのラインのスタートページが表示されます。「ワークベンチ」はなくなりました。ショートカットは ⌘1 対応待ち、⌘2 現在の worktree、⌘3 コミット履歴です。
