リリースノート

各バージョンの追加・改善・修正です。gtree をお使いの場合、新しいバージョンが出るとサイドバー下部に「更新して再起動」が表示されます。

v0.3.19最新

2026年10月28日 · ターミナルで ⌘ を押すだけで画像を表示、Git リポジトリでないフォルダも開ける、プロジェクトをドラッグで並べ替え

改善#

  • 内蔵ターミナルの画像をその場で見られるようになりました。⌘ を押しながら画像のパス(/tmp/shot.png、~/Desktop/a.jpg、今のフォルダからの相対パスなど)や、Claude Code で画像を貼り付けたときに出る「[Image #3]」にマウスを合わせると、横にプレビューが出ます。⌘ クリックで大きく開き、「Finder で表示」もできます。Agent が撮ったスクリーンショットや貼り付けた画像を、Finder で探す必要はもうありません。
  • ⌘O で Git リポジトリではない普通のフォルダも開けるようになりました。AI セッションやターミナル、ファイルの表示はそのまま使えます。スタートページと「履歴」ページの「Git リポジトリを作成」を押すと、Git プロジェクトになります。
  • サイドバーのプロジェクトをドラッグで並べ替えられるようになりました。次に開いたときもその順番です。
  • サイドバー下部のアップデートのカードが途中で切れなくなりました。次に新しいバージョンが出たときは、カードの「更新内容をすべて見る」から変更点を確認できます。

修正#

  • Claude Code をダークテーマにしていると、質問の本文が gtree の明るいターミナルで白地に白い文字になり、何も表示されていないように見えていた問題を修正しました。背景に近すぎる色の文字は、ターミナルが自動で読める色に調整します。
  • サイドバーの「マージ済み」グループの行をクリックすると、上の一覧に移動してクリックした場所から離れてしまう問題を修正しました。
  • 0.3.7 以前のバージョンから更新した後、初回の起動で一度だけ gtree が強制終了する問題を修正しました。

v0.3.18

2026年10月28日 · ファイル画面で定義へ移動、検索は右パネルへ、差分のファイル一覧は折りたたみ可能に

改善#

  • ファイル画面で定義へ移動できるようになりました。⌘ を押しながら名前にカーソルを合わせると下線が付き、⌘ クリック、F12、右クリックメニューの「Go to Definition」でその場所へ移動して名前を選択します。定義が別のファイルにあれば、ファイル画面でそのファイルを開きます。同じ名前の定義が複数あるときは、パス、行番号、その行のコードを並べた選択画面が出ます。⌃- / ⌃⇧- で元のファイルと行へ戻る・進むことができます。Rust、JavaScript / TypeScript、Python、Go に対応し、言語サーバーのインストールは不要です。worktree ごとに初めてソースファイルを開いたとき、裏で少し準備が入ります。準備が終わるまでは移動しません。
  • ファイルをまたいだ検索(⌘⇧F)を右パネルに移し、「ファイル / 変更 / 検索」の 3 つ目のタブにしました。読んでいるコードを覆わなくなりました。結果をクリックするとメイン画面で開き、結果はパネルに残るので、続けて次の箇所を開けます。
  • 差分、未コミットの変更、「AI の各ターン」の左にあるファイル一覧を、細い帯に折りたたんでコードに場所を譲れるようになりました。次に開いたときも折りたたんだままです。
  • ⌘T とタブバーの「+」に「ターミナルを開く」を追加しました。「Claude Code を新しく開く」「Codex を新しく開く」の後に並びます。

修正#

  • 差分の右側のファイルの順番が左のファイルツリーと合っていなかった問題を修正しました。たとえば Dockerfile が config/ フォルダより前にあるのに、ツリーでは一番下に表示されていました。
  • 長い行を横にスクロールすると、コードと背景色が右パネルの境界線まで描かれ、パネルに一部が隠れているように見えていた問題を修正しました。
  • 検索結果からファイルを開いたとき、該当する行に移動しないことがあった問題を修正しました。

v0.3.17

2026年10月23日 · 差分の横スクロール、⌘⇧P コマンドパレットと Markdown / PDF プレビュー、折りたたんだプロジェクトでも使用中の worktree を表示

改善#

  • 差分の長い行が途中で切れなくなりました。内容は横にスクロールできます(トラックパッドで横にスワイプ、または下のスクロールバーをドラッグ)。行番号、ファイルの見出し、「⋯ 変更のない N 行」は左に固定され、一緒に動きません。「AI の各ターン」や未コミットの変更の詳細も同じです。
  • ⌘⇧P のコマンドパレットを追加しました。⌘P と同じ画面で、> から入力するとファイルではなくコマンドを探します。各コマンドにショートカットが表示され、いま実行できるものだけが並びます。
  • ファイル画面で Markdown(見出しで「プレビュー / ソース」を切り替え)と PDF(ページ単位で表示)をプレビューできます。「Markdown プレビュー」と「PDF プレビュー」はどちらも内蔵のプラグインで、最初から有効です。設定に新しく加わった「プラグイン」の節で無効にできます。
  • 履歴(⌘Y)の検索欄の右に「この worktree」の切り替え(⌘E)を追加しました。現在の worktree での会話だけを表示し、次回起動後も設定を覚えています。
  • サイドバーで折りたたんだプロジェクトでも、使用中の worktree は表示されます。タブが開いているもの、AI が動いているもの、あなたを待っているものは隠れなくなり、クリックで切り替えられます。
  • 配色を見直しました。AI 関連の色を紫からロゴの深い青緑に変え、ブランチ図の各ブランチの色を少し淡くし、ダークテーマでは赤・緑・琥珀色が明るめの色になります。

修正#

  • ⌘P / ⌘⇧P の画面を閉じたあとショートカットが効かなくなる問題、⌘P・⌘Y・新しいセッションの選択画面で検索欄をクリックすると画面が閉じてしまう問題を修正しました。
  • 新しく作った(まだ git に追加していない)ディレクトリがファイルツリーで名前のない 1 つのファイルとして表示され、中のファイルが 1 つも出てこない問題を修正しました。ファイルを 1 つずつ一覧にし、.gitignore で無視されているファイルもグレーで表示します。node_modules のような無視されているディレクトリは、開いたときに中身を一覧にします。
  • 「対応待ち」(「念のため確認」、「作業中」の行の下、関係図の線)に、相手のセッションがすでに終わっていて届くことのないメッセージや、gtree が agent の代わりに送る「[auto]」の通知が並ばなくなりました。「このターンを終えました」という自動通知も、ターンごとに積み重ならなくなりました。
  • 現在のプロジェクトを折りたたむと、選択中の worktree がグレーの背景のままプロジェクト名の間に並び、プロジェクトが選択されているように見えていた問題を修正しました。

v0.3.16

2026年10月15日 · 差分はすべてのファイルを一続きに、ファイル画面で画像と履歴を表示、プロジェクト名も変更可能に

改善#

  • 差分は GitHub のプルリクエストのように、変更されたすべてのファイルを一続きで表示するようになりました。下へスクロールするだけですべての変更を見られます。左のファイルをクリックするとそこへ移動し、ファイルの見出しをクリックすると折りたたみ・展開できます。「全文を表示 / 変更のみ」はファイルごとに切り替えられるようになりました。「AI の各ターン」や未コミットの変更の詳細も同じ表示になりました。
  • 差分で文字を選択すると、右上に「選択をコピー」が現れます。ファイルの見出しや「⋯ 変更のない N 行」の折りたたみ行は含めず、コードだけをコピーします。
  • ファイル画面で画像(PNG、JPG、WebP、GIF、SVG など)を開くと、収まる大きさに縮めて画像として表示します。SVG は「ソースを表示」に切り替えられます。大きすぎる画像はプレビューしません。
  • ファイル画面に「履歴」を追加しました。このファイルを変更したコミットを、ファイル名を変える前のものも含めて一覧にします。クリックすると、そのコミットで何が変わったかを差分で表示します。
  • サイドバーでプロジェクトを右クリックし「名前を変更」を選ぶと、その場で名前を変えられます。↩ で保存、esc で取り消し、空欄にするとフォルダ名に戻ります。新しい名前は「対応待ち」や通知、gtree が agent に伝えるプロジェクト名にも反映されます。

修正#

  • 「対応待ち」に戻った直後の数秒間、一覧が前回の状態のままで、サイドバーのバッジと合わない問題を修正しました。
  • worktree のフォルダからリポジトリを開くと「対応待ち」に同じリポジトリが 2 つ表示され、あなたを待っている agent も 2 回並び、agent に伝えるプロジェクト名も間違っていた問題を修正しました。

v0.3.15

2026年10月15日 · agent の作業中も軽く、agent へのメッセージは英語にも対応

改善#

  • agent が作業している間の gtree 自身の CPU 使用量がほぼ半分になりました。agent の状態を示す回転アイコンとベルは、画面のリフレッシュレートではなく毎秒約 12 回で描き直すようになりました。3 つの agent が作業中、1 つが待っている状態の計測で、gtree は 8.6% から 4.4%(1 コア換算)に下がりました。何も動いていないときは 1% 未満のままです。
  • gtree が agent に送る文章がアプリの言語に合わせて切り替わるようになりました。中国語表示なら中国語、それ以外は英語です。同じ worktree の別セッションがファイルを変更した直後の知らせ、別セッションからの伝言、セッション開始時の「誰が何をしているか」、gtree の MCP ツールの説明が対象です。
  • スタートページの「Claude Code に接続されていません」の案内をカードにしました。説明を 1 行いっぱいに表示し、ボタンはその下に並びます。
  • 初回のガイドの文章を今の画面に合わせました。同じ worktree の agent は同じファイルを触る前に互いに確認します。「AI の各ターン」と ⌘Y がタイムラインの代わり、「対応待ち」がコラボビューの代わりです。
  • 状態のツールチップの先頭を「Claude ·」から「AI ·」に変えました。Codex のセッションにも使われるためです。

修正#

  • 空のリポジトリで、ファイルツリーの読み込み中の表示が消えずに動き続けていました。
  • 英語または日本語の表示で、「履歴」で再生した会話に出るツールの手順(「src/theme.ts を編集」など)が中国語になっていました。
  • スタートページの同時変更ファイル一覧で、ファイルのパスが見えなくなるほど詰まることがありました。関係する worktree は 2 行目に移しました。
  • 「対応待ち」がもう存在しないワークベンチへ案内していたのをやめ、残りの件数だけを表示するようにしました。
  • 設定の Claude Code の各 hook の説明に、ワークベンチやタイムラインが出てこなくなりました。チームプランの説明から、すでに無料版にある「チームメンバー」を外し、中継サーバーは同期情報を転送するだけでデータは保存しないと明記しました。

v0.3.12

2026年10月14日 · 新しいレイアウト:ラインを選べば次にやることがわかる、サイドバーに MR の状態

改善#

  • 画面の構成を変えました。サイドバーは「対応待ち」「コミット履歴」とプロジェクトだけになりました。プロジェクト内のラインをクリックするとそのホームが開き、セッションがあれば会話、なければそのラインのスタートページが表示されます。「ワークベンチ」はなくなりました。ショートカットは ⌘1 対応待ち、⌘2 現在の worktree、⌘3 コミット履歴です。
  • スタートページには、そのラインの今の状況がそれぞれボタン付きで並びます。マージ済み(worktree を削除 / 新しいブランチで始める)、同じファイルを別の場所でも変更中(どれか見る)、未コミットの変更あり(変更を見る)、リモートに新しいコミット(プル)、未プッシュ(プッシュ)、開いている MR(MR を開く)、MR がまだない(MR を作成)、メインブランチより遅れている(リベース)。その下から Claude Code / Codex の新規起動、ターミナルを開く、エディタで開くができます。
  • 右のパネルを「ファイル」と「変更」の 2 つのタブにしました(⌥⌘B で開閉、⇧⌘E / ⌃⇧G で切り替え)。「変更」には未コミットのファイル(ステージとコミットはここで)と AI の各ターンが並び、ターンをクリックすると何を変えたかが中央に表示されます。これまでの「変更」ビューは「コミット履歴」に名前を変えました。
  • サイドバーのブランチの後ろに MR の状態を表示します。マージ前はプルリクエストのアイコン、マージ済みなら薄いマージのアイコンです。マウスを乗せると番号・タイトル・リンクが見られ、クリックするとブラウザで開きます。ログイン済みの glab か gh を使い、GitLab(セルフホストを含む)と GitHub に対応しています。どちらも入っていなければ表示しません。
  • サイドバーの各ラインの右端には目印を 1 つだけ表示します。AI セッションの状態(作業中、あなた待ちなど)、同じファイルを別の場所でも変更中(琥珀色の △)、または未コミットの変更の行数(「+24 −3」など)です。マウスを乗せると説明が出ます。
  • ブランチがマージ済みで使っていないラインは、サイドバー下部の「マージ済み · N」にまとめます。プラットフォーム上で squash マージされ、git では判別できないものも含みます。
  • サイドバーでラインを右クリックすると Git メニュー(プッシュ、プル、コミット、ブランチ切り替え、worktree の削除など)が開きます。worktree が多いときはプロジェクト名が上に固定され、いつでもクリックで折りたためます。
  • AI が作業中またはあなた待ちのラインは、どのページからクリックしてもその会話が直接開きます。
  • AI ページを開いても Claude Code が自動で起動しなくなりました。見るだけでセッションが増えることはありません。始めるときはスタートページの「Claude Code を新しく開く」をクリックするか ⌘T を押してください(Codex が入っていれば選べます)。
  • 過去の会話は AI ページ上部の小さなウィンドウ(⌘Y)で開くようになりました。入力して検索し、↩ で続きから、⌘↩ で閲覧のみ。一覧の会話をクリックしても続きから始められます。
  • Claude Code が動いているタブを ⌘W で閉じるときは確認が出ます。「今後は確認しない」を選んでも、設定で元に戻せます。

修正#

  • 「回答済み、返信待ち」のベルは、そのターミナルのタブに切り替えれば消えるようになりました。メッセージを送る必要はありません。
  • 「対応待ち」で行をクリックすると、その件のセッションのタブに切り替わります。一覧が更新されても、キーボードで選んだ行が別の行に移らなくなりました。
  • タイトルバーのボタンを素早くクリックしても、ウィンドウが拡大されなくなりました。
  • ターミナルで 2 行に折り返された長い URL も、⌘ を押しながらクリックで開けるようになりました。

v0.3.11

改善#

  • ワークベンチを worktree ごとに 1 行にし、緊急度でまとめました。対応が必要なもの(あなた待ち、マージの競合)が先頭に並び、変更がなく AI も作業していないものやブランチがマージ済みのものは折りたたまれます。1 行目にブランチ名を省略せずに表示し、2 行目に worktree 名と変更内容を表示します。ボタンはマウスを乗せたときだけ表示されます。

  • AI ページの「履歴」を「今日」「昨日」「過去 7 日間」「それ以前」に分け、スクロール中も見出しが上部に残るようにしました。

  • 「プロジェクトの関係図」が横に広がって右端が切れる問題と、「/」という名前のプロジェクトが表示される問題を修正しました。
