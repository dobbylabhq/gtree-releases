gtree がすること、5 つ

  1. 01お互いが見える同じファイルは先に相談
  2. 02必要なときだけ呼ぶ全プロジェクトを「対応待ち」1 つで
  3. 03やり直せる全ターンを記録、ワンクリックで戻す
  4. 04プロジェクト間で質問フロントのエージェントがバックエンドに直接
  5. 05iOS のテストを見守るシミュレーターを操作、いつでも交代
01お互いが見える

同じファイル? まず相談します。

エージェント同士がお互いの作業を把握し、同じファイルを編集する前に相談します。

2 つの worktree が同じファイルを変更すると、サイドバーに △。クリックで比較できます。

02必要なときだけ呼ぶ

ほかの作業へどうぞ。 必要なときに呼びます。

許可や返答が必要なときだけ通知。全プロジェクトのあなた待ちは「対応待ち」のいちばん上に。

  • 必要なときだけ通知、見ている間は静かに
  • 通知をクリックすれば、そのセッションへ
ターミナルを 4 つ切り替えてやっと気づいた。あのエージェント、許可待ちで 20 分止まっていた。

状態がひと目でわかる

  • 1Dock のバッジあなた待ちの件数(全プロジェクトの合計)
  • 回転この worktree のエージェントが作業中
  • ベルあなた待ち:許可や返信
  • △別の worktree もこのファイルを変更中

戻せて、聞けて、軽い。

    壊れたターンがあっても、ワンクリックで戻れます。

  • 04プロジェクト間で質問

    API に迷ったら、エージェントが向こうのエージェントに直接聞きます。相手の作業は止めません。

05iOS シミュレーター

エージェントの iOS テストを見守る。

macOS · Xcode が必要

ターミナルを並べるだけでは、できないこと。

ターミナルや tmux が管理するのはウィンドウです。中のエージェントが何をしていて、どのファイルを変更しているかは知りません。

チームプラン

個人版のすべてに加えて:

  • チームでの Diff とコメント開発中
  • チームメンバーの変更をリアルタイムで同期(git の push / pull を待たない)設計中
  • メンバー同士がぶつかったら、双方で判断設計中
  • 中継経由で数秒で届くチームメッセージ(git の同期を待たない)設計中
  • 中継サーバーは同期情報を転送するだけで、データは保存しません

  1. 「ターミナル」を開き、上の 1 行を貼り付けて Return を押します。
  2. 「アプリケーション」にインストールされ、終わると自動で起動します。
  3. 初回起動時に Claude Code か Codex に接続します。クリックひとつで、設定からも接続できます。
  4. 新しいバージョンが出ると、サイドバー下部に「アップデートして再起動」が表示されます。クリックするだけで、再インストールは不要です。

zip を直接ダウンロード初回は「開発元を検証できません」と表示されます。「完了」を押し、「システム設定 → プライバシーとセキュリティ」の下部で「このまま開く」を押してください。上のコマンドで入れればこの手順は不要です。
